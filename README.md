knowing that:

Sensibility = TP/(TP + FN)
Specificity = TN/(FP + TN)
Accuracy = (TP + TN) / total number of items
Precision = TP / (TP + FP)
F-score = 2 * (precision * sensibility) / (precision + sensibility)

The following results were obtained:

**- Accuracy: 0,9888 (98,88%)**
**- Sensibility: 0,9849 (98,49%)**
**- Specificity: 0,9926 (99,26%)**
**- Precision: 0,9924 (99,24%)**
**- F-score: 0,9887 (98,87%)**
